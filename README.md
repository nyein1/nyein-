# Industrial Orange — Wear OS Watch Face

A custom Watch Face Format (WFF v1) design inspired by the industrial, layered orange-and-black style in the supplied reference image. It is not an official SEVENFRIDAY product or logo.

## Build
GitHub Actions builds a debug APK on every push to `main`.
Open **Actions → Build Wear OS Watch Face APK** and download the `industrial-orange-watchface-apk` artifact when the run succeeds.

## Install
Install the APK on the Galaxy Watch Ultra2 (SM-L715F), then long-press the watch face and choose **Industrial Orange**. If direct phone installation is blocked, use Galaxy Wearable or ADB over Wi-Fi.

Watch Face Format is required for Wear OS watch faces from January 2026.
